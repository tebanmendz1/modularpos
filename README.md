# FacturaPOS Cloud

## Una plataforma para vender, controlar y hacer crecer su negocio

**FacturaPOS Cloud**, desarrollado por **DreamSoft Solutions**, reúne en un solo sistema las ventas, el inventario, la caja, los clientes, los empleados y la administración de su empresa.

Funciona desde computadoras, tabletas y dispositivos móviles con conexión a Internet. Cada negocio recibe únicamente los módulos que necesita y puede ampliar su plataforma a medida que crece.

## ¿Por qué elegir FacturaPOS Cloud?

- Centraliza las operaciones del negocio en una sola plataforma.
- Permite controlar varias sucursales y almacenes.
- Reduce errores en caja, inventario y facturación.
- Ofrece información clara para tomar mejores decisiones.
- Facilita el trabajo de vendedores, cajeros, supervisores y administradores.
- Se adapta a diferentes tipos de comercios.
- Conserva la información de la empresa de forma segura y persistente.
- Permite agregar nuevas funciones sin cambiar de sistema.

## Ferretería y despacho de mostrador

Un módulo diseñado especialmente para ferreterías y negocios donde una persona prepara el pedido y otra realiza el cobro.

El vendedor puede:

- localizar productos rápidamente;
- trabajar con sacos, tubos, metros, libras, quintales y otras unidades;
- asignar el cliente;
- colocar un nombre o referencia al pedido;
- agregar observaciones para almacén o patio;
- generar una lista de despacho;
- enviar la orden directamente a caja.

El cajero recibe la orden completa, la verifica y realiza el cobro sin volver a registrar los productos. El sistema mantiene los estados **En cola**, **Cobrado** y **Cancelado**.

## Continuidad de trabajo

FacturaPOS Cloud está preparado para mantener una cola de operaciones cuando existe una interrupción temporal de Internet. Al recuperar la conexión, el sistema sincroniza las operaciones compatibles y actualiza la información central.

La información principal se conserva en una base de datos persistente, evitando que las empresas y operaciones desaparezcan durante actualizaciones del sistema.
